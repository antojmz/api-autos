# libs/

Aquí van las **librerías compartidas** entre servicios y/o apps, cada una en su carpeta: `libs/<nombre>/`. Por ejemplo: tipos o esquemas de la API, clientes HTTP o utilidades comunes.

Todavía no hay ninguna. Para añadir una, sigue [docs/arquitectura.md](../docs/arquitectura.md#una-librería-compartida).
